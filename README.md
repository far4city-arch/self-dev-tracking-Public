# تطبيق "المتابعة والتطوير الذاتي" — أندرويد

مشروع أندرويد كامل (Kotlin + Jetpack Compose) مبني وفق مواصفات ملف "آليات المتابعة" وصورة "رحلة الإنجاز: 7 خطوات نحو مستقبل مزدهر".

## 🚀 أسهل طريقة لتنزيل APK جاهز على جوالك (بدون تنصيب أي برنامج)

هذا المشروع يحتوي على ملف بناء تلقائي (`.github/workflows/build-apk.yml`) يبني لك APK جاهزًا عبر خدمة GitHub المجانية:

1. أنشئ حسابًا مجانيًا على [github.com](https://github.com) إن لم يكن لديك حساب.
2. أنشئ مستودعًا (Repository) جديدًا فارغًا — اسمه مثلًا `self-dev-tracking`.
3. ارفع محتويات هذا المجلد (`SelfDevTracker`) بالكامل إلى المستودع. أسهل طريقة:
   - افتح صفحة المستودع على GitHub، اضغط **Add file > Upload files**.
   - اسحب كل الملفات والمجلدات من `SelfDevTracker` وأفلتها، ثم اضغط **Commit changes**.
4. اذهب إلى تبويب **Actions** أعلى صفحة المستودع. سيبدأ البناء تلقائيًا (قد يستغرق 3-5 دقائق).
5. بعد اكتمال البناء (علامة ✅ خضراء)، افتح آخر تشغيل (run) واضغط عليه، ثم في أسفل الصفحة تحت **Artifacts** ستجد ملف `self-dev-tracking-apk` — نزّله.
6. الملف المضغوط الذي نزّلته يحتوي على `app-debug.apk`. انقله إلى جوالك (عبر واتساب لنفسك، Google Drive، أو كابل USB).
7. على الجوال: اضغط على ملف APK لتثبيته. أول مرة سيطلب منك أندرويد السماح بـ"التثبيت من مصادر غير معروفة" — وافق، ثم أكمل التثبيت.

بهذه الطريقة تحصل على تطبيق مثبَّت فعليًا على جوالك دون الحاجة لأي جهاز كمبيوتر أو Android Studio.

## الطريقة البديلة: البناء عبر Android Studio (لمن يفضل ذلك)
1. ثبّت **Android Studio** (أحدث إصدار مستقر).
2. افتح Android Studio ثم `Open` واختر مجلد `SelfDevTracker` هذا.
3. دع Gradle يزامن المكتبات تلقائيًا (يحتاج اتصال إنترنت في هذه الخطوة فقط، من جهازك أنت).
4. اضغط ▶ Run لتشغيل التطبيق على محاكي أو جهاز حقيقي (الحد الأدنى Android 8.0 / API 26).
5. يمكنك توليد ملف APK جاهز للتوزيع عبر: `Build > Build Bundle(s) / APK(s) > Build APK(s)`.

> ملاحظة: لم يتم بناء ملف APK هنا لأن بيئة العمل الحالية لا تملك اتصالًا بخوادم Google Maven/Android SDK. المشروع كود مصدري كامل وجاهز للبناء مباشرة من Android Studio.

## كيف تحقق كل بند من المواصفات

| المواصفة | التنفيذ في المشروع |
|---|---|
| اللغة: عربية بخاصية التيامن | واجهة عربية بالكامل + فرض اتجاه RTL في `Theme.kt` وaندros `supportsRtl` في Manifest |
| الألوان: غامقة | نظام ألوان Material3 غامق ثابت في `Color.kt` و `Theme.kt`، لا يتأثر بإعداد النظام |
| الأيقونات: أفقية رئيسية تنسدل منها الفرعيات | `CategoryTopBar.kt` — شريط أيقونات أفقي، كل أيقونة تفتح قائمة منسدلة بالفرعيات |
| بدون تسجيل دخول أو كلمة مرور | لا توجد أي شاشة دخول؛ `MainActivity` يفتح مباشرة على الشاشة الرئيسية |
| الحجم: أقل ما يمكن | لا مكتبات إضافية غير ضرورية، قاعدة بيانات محلية خفيفة (Room)، بدون صور أو موارد ثقيلة |
| المشغل: نظام اندرويد | `minSdk 26`, Kotlin + Jetpack Compose |
| الخطة الرئيسية (السباعية الأهداف) | 7 بطاقات ثابتة في `LifeGoal.kt` مأخوذة من صورة "رحلة الإنجاز: 7 خطوات نحو مستقبل مزدهر"، تُعرض في `SevenGoalsGrid.kt` وكل بطاقة تفتح سجل متابعة خاصًا بها |
| مهام التطوير الصوتي / الحركي / اللهجة / الحضور الذهني / الابتسامة / المظهر | كل فئة معرّفة بأيقونتها وفرعياتها في `GoalCategory.kt` |
| آلية التنبيه (8ص صوت هادئ / 10ص وميض بصري / 12ظ اهتزاز 5 ثوانٍ، أيام العمل فقط) | `AlarmScheduler.kt` + `AlarmReceiver.kt` + `NotificationHelper.kt`، مع تخطي الجمعة والسبت |
| آلية المتابعة: خانات إدخال + علامة (+) للإضافة | زر (+) عائم `FloatingActionButton` في كل شاشة فئة، وخانة (+) في الشاشة الرئيسية |
| تاريخ إجراءات المتابعة يظهر آليًا | `createdAt` يُسجَّل تلقائيًا عند الحفظ ويُعرض بصيغة تاريخ/وقت في `CategoryDetailScreen.kt` |
| عنوان الإجراء يُلخّص آليًا بأقل عدد كلمات | `TitleSummarizer.kt` — يستخرج أهم الكلمات ويحذف أدوات الربط، بدون إنترنت |

## بنية المشروع
```
app/src/main/java/com/selfdev/tracking/
├── MainActivity.kt              نقطة الدخول والتنقل بين الشاشات
├── data/                        النماذج وقاعدة البيانات المحلية (Room)
├── notification/                جدولة وتنفيذ التنبيهات الثلاثة اليومية
├── ui/theme, ui/components, ui/screens   واجهة Compose بالكامل
├── util/TitleSummarizer.kt      تلخيص عنوان الإجراء آليًا
└── viewmodel/                   ربط الواجهة بقاعدة البيانات
```

## ملاحظات مهمة
- التطبيق **لا يستخدم الإنترنت إطلاقًا**؛ كل البيانات تُخزَّن محليًا على الجهاز (Room/SQLite).
- عند أول تشغيل سيُطلب إذن الإشعارات (مطلوب من أندرويد 13 فأعلى) لتفعيل التنبيهات الثلاثة.
- أيام العمل مضبوطة حاليًا على (الأحد–الخميس) بما يناسب دولة قطر؛ يمكن تعديلها بسهولة من `AlarmReceiver.kt`.
- الأيقونات والألوان في المشروع مبدئية وقابلة للاستبدال بهوية بصرية جاهزة إن رغبت.
